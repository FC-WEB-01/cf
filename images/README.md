# Visuels du site

Les trois fichiers locaux sont intégrés directement dans `index.html` :

- `epargne-mobile.webp` — accueil, 800 × 600 px ; chargement prioritaire.
- `assurance-vie.webp` — assurance-vie, 256 × 256 px.
- `per.webp` — plan d’épargne retraite, 256 × 256 px.

Les images produits utilisent le chargement différé natif. Les dimensions HTML et les ratios CSS réservent leur espace. Les cadres Vie Plus, BNP Paribas Cardif et portrait du conseiller restent en attente de leurs fichiers.
