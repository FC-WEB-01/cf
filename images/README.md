# Visuels du site

Les fichiers locaux sont intégrés directement dans `index.html` :

- `epargne-mobile.webp` — accueil, 800 × 600 px ; chargement prioritaire.
- `assurance-vie.webp` — assurance-vie, 256 × 256 px.
- `per.webp` — plan d’épargne retraite, 256 × 256 px.

Les images produits utilisent le chargement différé natif. Les dimensions HTML et les ratios CSS réservent leur espace. Le fichier `portrait.webp` est intégré dans la section Contact (1122 × 1402 px, portrait illustratif généré par IA). Les cadres Vie Plus et BNP Paribas Cardif restent en attente de leurs fichiers.
